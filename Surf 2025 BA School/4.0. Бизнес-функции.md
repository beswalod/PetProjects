# 4.0. Бизнес-функции системы

## 1. Таблица бизнес-функций (роль → действие → результат)

| ID | Роль | Действие | Результат / изменение в системе | Сущности | State-transition |
|---|---|---|---|---|---|
| BF-01 | Студент | Просмотреть расписание по группе и дате | Отображён актуальный список занятий | `Group`, `Lesson`, `Teacher`, `Room` | `ScheduleScreen: loading → loaded` |
| BF-02 | Студент | Подписаться на событие | Создана регистрация участника | `Event`, `EventRegistration` | `not_registered → pending/confirmed` |
| BF-03 | Студент | Оставить комментарий к посту | Комментарий добавлен в ленту | `Post`, `Comment` | `Comment: draft → published` |
| BF-04 | Студент | Подать заявку в администрацию | Заявка зарегистрирована с SLA | `Ticket`, `TicketCategory` | `draft → submitted` |
| BF-05 | Сотрудник администрации | Взять заявку в работу | Назначен ответственный, изменён статус | `Ticket` | `submitted → in_review` |
| BF-06 | Сотрудник администрации | Завершить обработку заявки | Зафиксировано решение, отправлено уведомление | `Ticket`, `TicketStatusHistory` | `in_review → completed/rejected` |
| BF-07 | Студент | Записаться на консультацию | Забронирован слот преподавателя | `ConsultationSlot`, `ConsultationBooking` | `available → reserved`, `created → booked` |
| BF-08 | Преподаватель | Открыть слоты консультаций | Слоты стали доступны студентам | `ConsultationSlot` | `planned → available` |
| BF-09 | Администрация/редактор | Опубликовать FAQ-статью | Статья доступна в поиске | `FaqArticle`, `FaqCategory` | `draft → published` |
| BF-10 | Студент | Оценить полезность FAQ | Сохранена обратная связь для улучшений | `FaqFeedback` | `none → rated` |
| BF-11 | Модератор | Опубликовать новость/анонс | Пост появился в ленте | `Post` | `moderation → published` |
| BF-12 | Система | Отправить уведомление об изменении статуса | Пользователь получил push/in-app уведомление | `Ticket`, `Notification`* | `queued → delivered/read` |

\*`Notification` — прикладная сущность инфраструктуры уведомлений (может быть добавлена в ER на следующей итерации).

## 2. Трассировка функций к ER и state-моделям

| Функция | Связанные сущности ER | Связанная state-модель |
|---|---|---|
| BF-04, BF-05, BF-06 | `Ticket`, `TicketStatusHistory`, `TicketCategory` | `Ticket: draft → ... → closed` |
| BF-07, BF-08 | `ConsultationSlot`, `ConsultationBooking`, `Teacher`, `Student` | `Slot: available/reserved`, `Booking: created → booked → ...` |
| BF-02 | `Event`, `EventRegistration`, `User` | `Registration: not_registered → confirmed` |
| BF-11 | `Post`, `User` | `Post: draft → moderation → published` |
| BF-09, BF-10 | `FaqArticle`, `FaqCategory`, `FaqFeedback` | `Article: draft/published/archived` |
